WhatsApp Scheduler

This extension runs locally. It requires Chrome, WhatsApp Web to be logged in, and the computer to be running at send time.

Attachment limit

The extension does not impose an artificial 8 MB attachment limit. WhatsApp Web still applies its own file-size and file-type limits.

Retries

Failed sends are retried once per minute, up to 10 attempts.

Important

WhatsApp Web UI changes can require selector updates. This extension does not bypass CAPTCHAs, rate limits, login checks, or other platform protections.
